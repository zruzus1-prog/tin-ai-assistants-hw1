# ДЗ-1 «Среда и контекст»: TiN и лазерный синтез

Рабочий фрагмент исследовательского проекта: извлечение условий синтеза TiN
из статьи, проверка по первоисточнику, память агента, граф и поиск литературы.
Статья: Popov et al. (2019), DOI [10.1038/s41598-018-37519-1](https://doi.org/10.1038/s41598-018-37519-1).

**Материалы подготовлены.** Пять комментариев, подтверждения сверки трёх источников
и трёх тезисов, а также приёмка сохранены в `student_review.json`.
Публичный URL и отправка формы — следующие отдельные действия.

## Проверка

Python 3.12. Команды из корня репозитория:

```console
python -m pip install -r requirements.txt
python checks/check.py all
python checks/replay_search.py
python checks/submission_ready.py
```

Все три проверки пройдены. Первые две проверяют структуру, цитаты и воспроизводимость
сохранённого поиска. Последняя проверяет запись подтверждений студента; она не
доказывает происхождение его текста и не заменяет содержательную оценку преподавателя.
Проверкам не нужны ключи, сеть или скачивание модели. Windows: можно открыть `CHECK.cmd`.
Для полного повторного выполнения ноутбуков — `requirements-notebooks.txt` и
локальные переменные по `.env.example`.

## Авторство и адаптации

Основные агентные прогоны: **DeepSeek V4.1 Flash Free в OpenCode 2.0.16**.
Подготовка среды, интеграция и дополнительные независимые проверки выполнены
с помощью отдельного ИИ-проверяющего. Ноутбуки и MCP взяты из материалов курса.
Есть настоящий запуск **AI4Science / Goose 1.50.0 / Yandex DeepSeek V4 Flash**.

`[порождено]` — текст ИИ; `[источник]` — исходные данные; `[написано]` —
комментарии, переданные и подтверждённые студентом в форме просмотра.
Независимая автоматическая проверка и подтверждение студента записаны отдельно.

Адаптации Windows, сокращение числа повторений и различия оболочек перечислены в
Прямое общее разрешение преподавателя считать любую оболочку эквивалентной не найдено;
такое разрешение здесь не утверждается. Ошибки и превышения бюджета сохранены.

Для публикации локальные абсолютные пути и название вспомогательной оболочки
обобщены. Это нормализованные копии журналов, не их побайтные оригиналы.
Подробности — [evidence/README.md](evidence/README.md).
