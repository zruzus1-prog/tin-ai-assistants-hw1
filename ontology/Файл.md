# Файл

Определение: конкретный файл проекта с относительным путём и определённым содержимым.

Родительский класс: нет.

[порождено] Публикация — экземпляр класса `Источник`, а её локальный PDF — экземпляр класса `Файл`. Факт — утверждение, строка которого может храниться в файле CSV. Связь с файлом задаётся отношением `хранитсяВ`.
